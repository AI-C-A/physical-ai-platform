# 제품 시연 가이드

이 순서는 **Mock 시뮬레이션**을 기준으로 한다. 실행 방법은 [README](../README.md#mock-실행)를 따른다. 시작 전에 `/control/monitoring`의 지도와 영상을 확인한다. 지도에는 Mapbox 연결 설정이 필요하다.

Mock의 로봇 상태·위치·영상과 수집 결과는 시뮬레이션이다. 실제 Quest 원본 수집이나 영구 저장이 완료되었다고 설명하지 않는다. Real은 연결된 Patrol 상태와 Kinesis 영상을 사용하며, 현재 수집·Episode·Dataset 쓰기와 Quest Backend 연결은 제공하지 않는다. 수집 화면의 깊이·분할 영상과 Unitree G1 기준 모델도 실시간 실기기 추론 결과로 소개하지 않는다.

## 관제

1. **사이트**를 선택하고 로봇 목록의 배터리·연결 상태를 보여준다. 좁은 화면에서는 **로봇 목록 보기 · N대**를 먼저 누른다.
2. **로봇 검색**에 이름이나 기체 번호를 입력한다. 검색란의 지우기 버튼으로 전체 목록을 복원한다.
3. 목록에서 로봇의 연결 상태와 배터리를 확인한다. 연결이 끊긴 기체와 충전 중인 기체의 표시를 구분해 설명한다.
4. 지도에서 로봇 번호 핀을 선택한다. 선택된 핀과 오른쪽 로봇 정보가 같은 기체인지 확인한다. **전체 위치**, **사이트 중심**, **위치 따라가기**를 차례로 보여준다. 위치가 없는 기체에서는 따라가기를 사용할 수 없다.
5. 로봇 정보의 **영상 관제**를 누른다. 영상을 확인한 뒤 상단 **나가기**로 돌아온다.
6. 목록 검색란 오른쪽 **선택**을 눌러 로봇을 2대 이상 선택하고 **다중 관제 시작**을 누른다. 최대 6대까지 선택할 수 있다. **구성 변경**으로 선택한 기체를 확인한 뒤 **나가기**로 돌아온다.

## 데이터 수집 → 카탈로그 → 데이터셋

1. 미니앱을 **MLOps**로 전환하고 **수집** → **새 수집**을 연다.
2. **세션 이름**을 정하고 **작업 ID**에 `task-sort-fruit`, **작업 지시**에 `과일을 종류에 맞는 트레이에 분류하세요.`를 입력한다. 시연용 **외골격 장치 ID**는 `exoskeleton-001`, **Quest 손 추적 장치 ID**는 `quest2-001`, **RBP 헤드 카메라 ID**는 `rbp-headcam-001`, **외부 카메라 ID · 선택**은 `external-camera-001`로 입력한 뒤 **세션 생성**을 누른다.
3. 표시된 **Quest 연결 코드**를 확인한다. 같은 브라우저의 별도 탭에서 현재 플랫폼의 `/collect/quest`를 열고 **6자리 페어링 코드**에 입력한 뒤 **세션 연결**을 누른다.
4. Quest 탭의 **MR 모드 시작**을 누른다. 왼손과 오른손에 **추적 정상**이 표시되는지 확인한다. 이 탭은 시연이 끝날 때까지 열어 둔다.
5. PC 수집 탭으로 돌아와 **수집 콘솔 열기**를 누른다. 세션을 열면 자동으로 점검하고 장치 상태가 바뀔 때 다시 확인한다. 연결 코드가 만료되었다면 **새 코드 받기**로 같은 세션에서 다시 연결한다.
6. **Episode 녹화 시작**을 누른다. 녹화 경과 시간과 손 추적을 보여준다. **수집 상세**의 **세션 정보**, **수집 상태**, **문제** 탭에서 기록 정보와 장치 상태를 확인한다. 선택된 탭을 다시 누르면 상세 패널이 닫힌다.
7. **녹화 정지**를 누른다. **원본 전송 중** 또는 **파일 확정 중**에는 장치 연결을 유지한다. Quest 탭의 **검토 대기**, PC의 **녹화본 검토 대기**까지 기다린다. 필요하면 **수집 상태** 탭에서 장치의 정지 명령 응답을 확인한다.
8. 재생 버튼과 재생 위치 슬라이더로 녹화본을 검토하고 **녹화본 저장**을 누른다. **저장 완료 1개**와 **다음 Episode 녹화 시작**을 확인한다.
9. 재녹화를 보여주려면 다음 Episode를 시작하고 정지·전송 완료를 기다린다. **다시 녹화** → **삭제하고 다시 녹화**를 누르면 방금 검토하던 녹화본을 삭제하고 새 녹화를 시작한다. 새 녹화본도 정지·검토 후 **녹화본 저장**한다.
10. 왼쪽 상단 닫기 버튼(**수집 콘솔 닫기**) → **저장하고 마치기**를 누른다. 처리가 끝나면 이동한 카탈로그에서 세션 이름과 저장한 에피소드 수를 확인한다.
11. 포함할 에피소드의 체크박스를 선택하고 **선택한 에피소드 N개로 데이터셋 구성**을 누른다. **이름**을 입력하고 선택한 데이터와 품질 상태를 확인한 뒤 **초안 생성**을 누른다. 생성된 데이터셋의 구성 항목으로 시연을 마친다.

연결이나 전송이 지연되면 **문제** 탭에 나온 상태를 설명하고 복구를 진행한다. 화면이 완료를 확인하기 전에는 저장·처리가 끝났다고 안내하지 않는다.
